The round: 100yd run → N×12 Bonnie Blairs → 100yd Bernie → N×12 HR Merkins → 25yd Bear Crawl → N×12 WW1s → 25yd Crawl Bear → N×12 Burpees. Reps go up 12 every round.

Scoring: every yard is a point and every rep is a point. A full round N is worth 250 + 48N; after N complete rounds you've banked 24N² + 274N.

Worked example — Ojos: finished rounds 1–4, then got the 100yd run and 2 Bonnie Blairs before time. That's 1480 banked + 100 + 2 = 1582.
